# Archives of Dreams Education Center

Professional school website starter built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Before deployment

Replace the school image placeholder with an official school photograph and confirm all school-provided information, including physical location, admissions details, donation/payment instructions, logo, and official copy.

The contact form is intentionally not connected to an email service yet. Connect and test a real form/email backend before publishing.
